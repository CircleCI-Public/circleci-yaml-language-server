# Security Policy

## Reporting a vulnerability

Please don't report security vulnerabilities in public GitHub issues.

Report them to [security@circleci.com](mailto:security@circleci.com), following
CircleCI's [responsible disclosure policy](https://circleci.com/security/).

## Supported versions

Only the [latest release](https://github.com/CircleCI-Public/circleci-yaml-language-server/releases/latest)
gets security fixes.
