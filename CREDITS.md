This list was generated from the libraries linked into the language server:

1. `task licenses`, which writes `licenses.csv` with [go-licenses](https://github.com/google/go-licenses)
2. Drop the language server itself from the CSV, and collapse the `gotest.tools/v3` packages, which go-licenses can't attribute individually, into one row
3. Replace the pinned version or commit in each license location with `HEAD`, so a dependency version bump alone doesn't require regenerating this file
4. Convert the CSV to a markdown table, with columns reordered to project, license name, license location
